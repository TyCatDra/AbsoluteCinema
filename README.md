# Absolute Cinema - System zarządzania siecią kin

Przygotowanie 3 modułów związanych z funkcjonowaniem sieci kin:
- moduł zarządzania infrastrukturą fizyczną oraz harmonogramem kina
- system sprzedaży, rezerwacji i kontroli biletów na seanse
- zaawansowany system lojalnościowy, udostępniający kupującym m.in. punkty lojalnościowe, poziomy członkostwa, wymianę punktów na zniżki.
